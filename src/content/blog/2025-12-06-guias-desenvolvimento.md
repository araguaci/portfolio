- [📚 Acessar Guias](https://guias.artesdosul.com/)

Coleção abrangente de **12 guias práticos e tutoriais** sobre desenvolvimento de software, DevOps, inteligência artificial e tecnologias modernas. Os guias cobrem desde conceitos básicos até tópicos avançados, oferecendo instruções passo a passo, exemplos práticos e melhores práticas para ajudar desenvolvedores e profissionais de TI a implementar soluções eficientes e modernas.

## Desenvolvimento Web

### Guia Flask
Framework web Python para desenvolvimento rápido de aplicações web. Aprenda a criar APIs, rotas, templates e integrar com bancos de dados.

### Guia Git/GitHub
Domine o controle de versão com Git e GitHub. Comandos essenciais, workflows, branches, pull requests e colaboração em equipe.

## Containerização e DevOps

### Guia Docker
Aprenda a usar Docker para containerização de aplicações. Criação de imagens, containers, volumes e networking.

### Guia Docker Compose
Orquestre múltiplos containers com Docker Compose. Configure ambientes completos de desenvolvimento e produção com arquivos YAML.

### Guia Nginx
Configure e otimize servidor web Nginx. Reverse proxy, load balancing, SSL/TLS e configurações avançadas de performance.

## Backend e Banco de Dados

### Guia Supabase
Backend como serviço com Supabase. Autenticação, banco de dados PostgreSQL, storage, funções serverless e APIs em tempo real.

## Inteligência Artificial

### Guia LLM
Trabalhe com Large Language Models. Integração, fine-tuning, prompts engineering e aplicações práticas de IA generativa.

### Guia Gemini CLI
Use Google Gemini via linha de comando. Automação, scripts e integração do modelo de IA em workflows de desenvolvimento.

### Guia MCP
Model Context Protocol para integração de modelos. Padronização de comunicação entre aplicações e modelos de IA.

### Guia Agente Autônomo
Crie agentes autônomos com IA. Desenvolvimento de sistemas inteligentes que tomam decisões e executam tarefas de forma independente.

## Tecnologias Modernas

### Guia MVP
Desenvolva um Minimum Viable Product eficiente. Metodologias, validação, iteração rápida e lançamento de produtos.

### Guia WASM
WebAssembly para aplicações web de alto desempenho. Compilação, integração com JavaScript e otimização de performance.

## Estrutura dos Guias

Cada guia oferece:
- **Instruções passo a passo** detalhadas
- **Exemplos práticos** e código funcional
- **Melhores práticas** e padrões de desenvolvimento
- **Troubleshooting** e soluções para problemas comuns
- **Recursos adicionais** e referências

Todos os guias estão disponíveis em formato HTML responsivo, com navegação intuitiva e interface moderna, facilitando o aprendizado e a consulta rápida durante o desenvolvimento.
