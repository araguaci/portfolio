## ❓ Perguntas Frequentes

### O que é um website e por que preciso de um?

Um website é uma coleção de páginas interligadas, acessível pela internet via navegador e identificada por um URL exclusivo. 

**Um site profissional pode conter:**
- 📝 Informações, artigos, portfólio e notícias
- 🖼️ Galeria de produtos, fotos e ilustrações
- 🎬 Vídeos demonstrativos e tutoriais
- 🔗 Conexões com redes sociais e parceiros
- 📨 Formulários de contato e captura de leads
- ⚡ Funcionalidades interativas e dinâmicas

**Estrutura básica eficaz:**
- 🏠 Home impactante com proposta de valor clara
- 📄 Páginas de serviços/produtos com detalhes
- 👤 Sobre que transmite confiança e credibilidade
- 📬 Contato facilitado para conversão

Construímos com HTML para estrutura, CSS para visual e JavaScript para dinamismo, integrando tecnologias conforme necessidade específica do projeto.

### Quanto tempo leva para criar um site?

Depende da complexidade:
- Site institucional simples: 3-4 semanas
- Site corporativo médio: 6-8 semanas
- E-commerce completo: 8-12 semanas
- Sistema customizado: 12+ semanas

Trabalhamos com entregas incrementais, então você vê progresso real a cada sprint.

### Qual o investimento necessário?

Cada projeto é único. O valor depende de:
- Escopo de funcionalidades
- Complexidade de design
- Integrações necessárias
- Volume de conteúdo
- Requisitos de performance e segurança

Oferecemos orçamento transparente após entender suas necessidades específicas. Agende uma consultoria gratuita para estimativa personalizada.

**Importante:** SEO técnico (que fazemos) garante que o Google consiga indexar seu site corretamente. Ranking orgânico depende também de conteúdo de qualidade, autoridade de domínio e estratégia de longo prazo.
